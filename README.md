# 📚 Expense Tracker - Python

This project is a **menu-driven Expense Tracker** developed using **Python**. It allows users to record, manage, and analyze daily expenses efficiently while storing data permanently in a JSON file.

---

# 💰 Expense Management Features

* ➕ Add Expense
* 📋 View Expenses
* 🔍 Search Expense
* ✏️ Update Expense
* 🗑 Delete Expense
* 💵 Total Expense
* 📊 Expense Analysis
* 💾 JSON File Storage
* ✅ Input Validation

---

# 🛠 Technologies Used

* Python 3
* JSON
* File Handling

# ▶️ How to Run

1. Install Python 3 on your system.
2. Clone this repository.

```bash
git clone https://github.com/ronakjawaliya-ux/Expense-Tracker-Python.git
```

3. Open the project folder.

```bash
cd Expense-Tracker-Python
```

4. Run the program.

```bash
python expense_tracker.py
```
